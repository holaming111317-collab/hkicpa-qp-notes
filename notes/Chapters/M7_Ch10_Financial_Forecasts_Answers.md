**Question 1 — Correct answer: C (Notes payable)**

**Model answer:**
In the percent-of-sales method, accounts that vary directly with sales (cash, accounts receivable, inventory, accounts payable, and — at full capacity — net fixed assets) are projected as a percentage of sales. Notes payable, long-term debt and common stock are marked 'n/a': they change only when management decides to borrow, repay, issue or repurchase, so the current year's value is carried into the preliminary pro forma statement. The resulting imbalance is the plug value, usually the external funding needed (EFN).

**【解題思路】**
- 關鍵考點係「自發性 vs 酌情性賬項」：銷售上升會自然帶動應收賬款、存貨、應付賬款同現金，但 notes payable 只會因管理層主動借貸或還款先變。
- A (Accounts payable) 錯：應付賬款隨銷售自發增加（賣得多→入貨多），係自發性資金來源，會減少 EFN。
- B (Inventory) 錯：存貨係營運資金賬項，歷史數據顯示維持在銷售的固定百分比，必須隨銷售預測上調。
- D (Accounts receivable) 錯：賒銷增加自然推高應收賬款，同樣以銷售百分比預測。
- 記住初步 pro forma 中「n/a」三兄弟：notes payable、long-term debt、common stock；retained earnings 就從 pro forma 損益表嘅 addition to retained earnings 推算。

**Question 2 — Correct answer: B**

**Model answer:**
Project FCF is computed on a 'stand-alone' basis excluding financing effects. Interest expense is excluded because (1) it isolates the cash flows generated by the project itself, and (2) the cost of debt and equity financing — including the tax impact of debt — is already captured in the discount rate used in the NPV analysis. Project taxes are computed as EBIT × the company's marginal tax rate (taxes owed as if no debt financed the project), because project profits are incremental to existing profits.

**【解題思路】**
- A 錯：扣利息會同折現率重複計算融資成本；而且項目稅項應用**邊際稅率 (marginal tax rate)**，唔係平均稅率。
- C 錯：利息稅務扣減 (interest tax shield) 嘅效果已反映喺折現率入面，唔應再放入項目 FCF。
- D 錯：折舊雖然係非現金支出，但係可以扣稅——正確做法係先扣 D&A 計稅（EBIT × (1−t)），再加回 D&A 得出 CF Opns；唔可以喺計稅時剔除折舊。
- 口訣：「融資入折現率，稅用邊際率，折舊先扣後加回」。

**Question 3 — Correct answer: B**

**Model answer (working):**
- Contribution margin per unit = Price − Unit VC = 200 − 120 = HK$80
- Pre-tax operating cash flow (EBITDA) break-even = FC / CM = 24,000 / 80 = 300 units
- Accounting operating profit (EBIT) break-even = (FC + D&A) / CM = (24,000 + 6,000) / 80 = 375 units
- The EBIT break-even is higher because D&A is added to the numerator.

**【解題思路】**
- 第一步問自己：分子包唔包 D&A？EBITDA break-even（pre-tax operating cash flow）只放 FC = 24,000，所以 300 單位；EBIT break-even（accounting operating profit）要放 FC + D&A = 30,000，所以 375 單位。
- A 錯：375 係 **EBIT** break-even，唔係 EBITDA break-even——調轉咗。
- C 錯：300 係 EBITDA break-even；會計利潤打和要連折舊攤銷一齊 cover，必定較高。
- D 錯：EBITDA break-even 分子較細，單位數一定**低過** EBIT break-even，唔會高過。
- 本題剛好係整數，唔使進位；如遇小數（例如 166.67）記住向上進位到下一個整單位。

**Question 4 — Correct answer: FCF = HK$1,400,000**

**Model answer (full working):**

| Step | Item | HK$ |
|---|---|---|
| Revenue | | 9,000,000 |
| − Op Ex | | (6,000,000) |
| = EBITDA | | 3,000,000 |
| − D&A | | (1,000,000) |
| = EBIT | | 2,000,000 |
| × (1 − t) | × (1 − 0.25) = 0.75 | |
| = NOPAT | | 1,500,000 |
| + D&A | | 1,000,000 |
| = CF Opns | | 2,500,000 |
| − Cap Exp | | (800,000) |
| − Add WC | | (300,000) |
| = **FCF** | | **1,400,000** |

Equivalently: FCF = [(9,000,000 − 6,000,000 − 1,000,000) × 0.75] + 1,000,000 − 800,000 − 300,000 = 1,500,000 + 1,000,000 − 1,100,000 = HK$1,400,000.

**【解題思路】**
- 跟足 FCF 鏈：EBITDA → EBIT → NOPAT → 加回 D&A → CF Opns → 減 Cap Exp 同 Add WC。
- 常見錯誤 1：唔記得加回 D&A——折舊係非現金，扣完稅之後要加返，否則會少計 HK$1,000,000，錯答 HK$400,000。
- 常見錯誤 2：用 EBITDA（3,000,000）而唔係 EBIT（2,000,000）嚟計稅——稅應該係 EBIT × 25% = 500,000，唔係 750,000。
- 常見錯誤 3：忘記減增量營運資金 (Add WC)——Cap Ex 同 Add WC 都係必要投資，兩者都要扣，漏扣會錯答 HK$1,700,000。
- 考試貼士：呢類題目 2.5 分鐘內要搞掂，畫返條鏈出嚟逐行填數最穩陣。

**Question 5 — Correct answer: EFN = HK$84,000**

**Model answer (full working):**
1. Forecast sales: S₁ = 5,000,000 × 1.20 = HK$6,000,000; increase in sales ΔS = HK$1,000,000
2. Increase in assets required = 50% × ΔS = 0.50 × 1,000,000 = HK$500,000
3. Spontaneous increase in accounts payable = 8% × ΔS = 0.08 × 1,000,000 = HK$80,000
4. Projected taxable income = 6,000,000 × (1 − 0.80) = HK$1,200,000
5. Projected net income = 1,200,000 × (1 − 0.30) = HK$840,000
6. Addition to retained earnings = 840,000 × (1 − 0.60) = 840,000 × 0.40 = HK$336,000
7. EFN = Increase in assets − Spontaneous increase in AP − Addition to retained earnings
   = 500,000 − 80,000 − 336,000 = **HK$84,000**

**【解題思路】**
- EFN 邏輯 = plug value：新資產需求（500,000）先由自發資金填——應付賬款增加（80,000）同留存盈利增加（336,000）——唔夠嘅部分先要靠外部融資。
- 常見錯誤 1：用舊銷售 5,000,000 而唔係新銷售 6,000,000 嚟計淨利——派息同留存係基於**預測年度**嘅盈利。
- 常見錯誤 2：用 payout ratio (60%) 而唔係 retention ratio (40%) 計留存增加——留存增加 = 淨利 × (1 − payout)，用錯會得 840,000 × 0.6 = 504,000，EFN 變成負數。
- 常見錯誤 3：以全部資產 (50% × 6,000,000 = 3,000,000) 做分子——EFN 只關心**增量** (50% × ΔS)。
- 常見錯誤 4：忘記扣自發增加嘅應付賬款——AP 係免費嘅自發資金來源，會減少外部融資需求。
- 考試貼士：EFN 三部曲——「資產增量 − 自發負債增量 − 留存盈利增量」，記住呢條式就唔會亂。
