## 第六部分：M7 Ch3 Time Value of Money 高頻詞（W3）
| 英文 | 中文意思 | 考試點 |
|---|---|---|
| simple interest | 單利 | P×i×n，利息唔滾利息 |
| compound interest | 複利 | P×(1+i)ⁿ，利息滾利息 |
| present value (PV) / future value (FV) | 現值 / 終值 | 決策：唔好俾多過個 PV |
| discounting / compounding | 折現 / 複利計算 | 方向相反：PV = FV ÷ (1+i)ⁿ |
| ordinary annuity | 普通年金 | **期末**收付 |
| annuity due | 期初年金 | **期初**收付（如租金）= ordinary × (1+i) |
| perpetuity | 永續年金 | PV = CF ÷ i（首期一年後）|
| growing perpetuity | 增長永續年金 | PV = PMT₁ ÷ (k − g)，**必須 k > g** |
| nominal rate / APR | 名義利率 | 唔計複利效果 |
| effective annual rate (EAR) | 實際年利率 | (1 + i/m)ᵐ − 1；複利越密 EAR 越高 |
| compounding frequency | 複利頻率 | semi-annual / monthly / daily… |
| opportunity cost | 機會成本 | 即係你個 discount rate |
| annualize | 年化 | 期內回報 × (360 ÷ 日數)；BEY 最後一步，漏咗 = 錯 |
| holding-period yield | 持有期回報 | 未年化嘅回報，**唔係** quoted annual yield |
| bankers' acceptance (BA) | 銀行承兌匯票 | 1–180 日，money market 短期融資 |
| declining / negative-growth perpetuity | 縮減永續年金 | g 係負數都照用：PV = PMT₁ ÷ (r − g) |
| annuity factor | 年金系數 | [1 − (1+r)⁻ⁿ] ÷ r；n 大嗰陣快過逐期折現 |

## 第十部分：M7 Ch6 CAPM 高頻詞
| 英文 | 中文意思 | 考試點 |
|---|---|---|
| systematic risk / market risk | 系統性風險 / 市場風險 | 影響成個市場（利率、通脹、衰退），分散投資**散唔走** |
| unsystematic risk / specific risk | 非系統性風險 / 個別風險 | 單一公司嘅風險（罷工、訴訟），分散投資可以散走 |
| beta (β) | 啤打系數 | 量度個股對市場嘅敏感度；β=1 跟大市、β>1 放大、β<1 防守 |
| CAPM | 資本資產定價模型 | E(R) = Rf + β × (E(Rm) − Rf) |
| market risk premium (MRP) | 市場風險溢價 | E(Rm) − Rf；係 SML 嘅**斜率**，唔係 beta |
| Security Market Line (SML) | 證券市場線 | x 軸係 **beta**、y 軸係 required return；斜率 = MRP |
| above / below the SML | 喺 SML 之上 / 之下 | actual return > required return → 喺線上 = **undervalued**（抵買）；反轉 = overvalued |
| portfolio beta | 投資組合啤打 | 加權平均：βp = Σ wi × βi |
| risk-free rate (Rf) | 無風險利率 | CAPM 嘅 intercept，通常用政府債券息率 |
| diversification | 分散投資 | 只可以消除 unsystematic risk，消唔到 systematic risk |
