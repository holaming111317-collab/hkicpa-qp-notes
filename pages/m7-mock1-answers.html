M7 Mock Examination 1 — Model Answers（完成測驗後先好睇！）

Question 1 — Correct Answer: 9.17%

Model Answer (English): - Cost of equity (dividend growth model): kₑ = D₁/P₀ + g = 0.50/8.00 + 5% = 6.25% + 5% = 11.25% - Market values: E = 1,000,000 × 8.00 = 8,000,000; D = 4,000,000; V = 12,000,000 - WACC = (8/12)(11.25%) + (4/12)(6%)(1 − 0.165) = 7.50% + (1/3)(5.01%) = 7.50% + 1.67% = 9.17%

【解題思路】 - 三寶：權重用 market value（股數 × 股價，唔係面值）、kₑ 用 DGM（D₁/P₀ + g）、只有債有稅盾 ×(1 − t)。 - 呢條係你嘅頭號惡魔（第五次交手先斬）——Mock 入面再錯嘅話，每日默寫 WACC 直至考試日。

Question 2 — Correct Answer: C

Model Answer (English): "Ordinary shares are traded on the capital market (long-term funds). Money market instruments are short-term (one year or less): treasury bills, commercial paper and certificates of deposit."

【解題思路】 - Money market = 短期（≤1 年）；capital market = 長期。普通股冇到期日 → capital market。

Question 3 — Correct Answer: B

Model Answer (English): "A manager rewarded on ROI will reject a project whose return exceeds the company's required rate but falls below the division's current ROI — a dysfunctional decision that residual income avoids."

【解題思路】 - 25% 本位主義：接受 20% 項目會拖低部門 ROI → 拒絕，即使對公司有利。RI 先做到 goal congruence。

Question 4 — Correct Answer: 12.68%

Model Answer (English): "EAR = (1 + 0.12/12)¹² − 1 = (1.01)¹² − 1 = 1.1268 − 1 = 12.68%"

【解題思路】 - EAR = (1 + r/n)ⁿ − 1。月複利 n = 12。唔好直接答 12%（嗰個係 nominal）。

Question 5 — Correct Answer: 24%

Model Answer (English): "ROE = net profit margin × total asset turnover × equity multiplier = 8% × 1.5 × 2.0 = 24%"

【解題思路】 - DuPont 三步直乘，唔使分開計 ROA。8 × 1.5 = 12（ROA），× 2 = 24。

Question 6 — Correct Answer: C

Model Answer (English): "Under MM Proposition I (no taxes), firm value is independent of capital structure. As gearing rises, the cost of equity rises to compensate shareholders for the additional financial risk, leaving the WACC unchanged."

【解題思路】 - Zero tax 世界：value 唔變、WACC 唔變、kₑ 升。平債冇免費午餐——風險轉嫁畀股東。

Question 7 — Correct Answer: HK$949.24

Model Answer (English): "Semi-annual periods: n = 6, r = 5% per period, coupon = 1,000 × 8% / 2 = HK$40. Price = 40 × annuity factor(5%, 6) + 1,000 × PV factor(5%, 6) = 40 × 5.0757 + 1,000 × 0.7462 = 203.03 + 746.22 = HK$949.24"

【解題思路】 - 半年複利：息率減半（10%→5%）、期數加倍（3→6）、coupon 減半（80→40）。 - 常識檢查：coupon 8% < YTM 10% → 一定折價（低過 1,000）。計出嚟高過面值 = 即刻知錯。

Question 8 — Correct Answer: (i) HK$120 (ii) 20%

Model Answer (English): "Total cost per unit = 60 + 30 + 10 = HK$100. Selling price = 100 + 20 = HK$120. Mark-up on total cost = 20/100 = 20%."

【解題思路】 - Total cost 包晒 fixed manufacturing OH 同 fixed S&A OH；利潤只加一次（你嘅舊債：雙重計利潤——target price 砌好咗就唔好再 × mark-up）。

Question 9 — Correct Answer: 10.2%

Model Answer (English): "kₑ = Rf + β(Rm − Rf) = 3% + 1.2 × (9% − 3%) = 3% + 7.2% = 10.2%"

【解題思路】 - 注意係 market risk premium（Rm − Rf = 6%），唔係成個 Rm 乘 β。

Question 10 — Correct Answer: NPV = +HK$41,225（accept）

Model Answer (English): "PV of inflows: Y1 = 100,000/1.1 = 90,909; Y2 = 100,000/1.21 = 82,645; Y3 = (100,000 + 30,000 NWC recovered)/1.331 = 130,000 × 0.7513 = 97,671. Total PV = 271,225. NPV = 271,225 − (200,000 + 30,000) = +41,225 → accept."

【解題思路】 - NWC 兩頭計：t0 流出（加入 initial outlay）、期末收回折現後加返。兩個位漏一個就錯（你嘅舊債）。

Question 11 — Correct Answer: 12.5%

Model Answer (English): "MM Proposition II (no tax): kₑ = k₀ + (D/E)(k₀ − kd) = 10% + 0.5 × (10% − 5%) = 10% + 2.5% = 12.5%"

【解題思路】 - 括號入面係 k₀ − kd（5%），再乘 D/E（0.5）。唔好掉轉做 kd − k₀。

Question 12 — Correct Answer: 60.0%

Model Answer (English): "LTV = amount borrowed ÷ total value of the asset = 360,000 ÷ 600,000 = 0.60 = 60.0%"

【解題思路】 - LTV 越低越安全；題目要求一位小數 → 60.0%。

Question 13 — Correct Answer: HK$300,000

Model Answer (English): "EFN = ΔA − ΔAP − retained earnings ΔA = 60% × 2,000,000 = 1,200,000 ΔAP = 15% × 2,000,000 = 300,000 Net income = 10% × total sales of 12,000,000 = 1,200,000; retained = 1,200,000 × 50% = 600,000 EFN = 1,200,000 − 300,000 − 600,000 = HK$300,000"

【解題思路】 - 三大陷阱（你中晒過）：NI 用 total forecast sales（12M）唔係 ΔS；retained 係減唔係加；ΔAP 唔好漏。

Question 14 — Correct Answer: C

Model Answer (English): "Production cycle time is an internal process perspective measure. Financial = ROI/EVA; customer = market share/satisfaction; learning and growth = staff skills and training."

【解題思路】 - BSC 四維度歸類題係送分——internal process = 生產/營運效率指標。

Question 15 — Correct Answer: HK$10,660,000

Model Answer (English): "MM with corporate taxes: V_L = V_U + T_c × D = 10,000,000 + 0.165 × 4,000,000 = 10,000,000 + 660,000 = HK$10,660,000"

【解題思路】 - Tax shield 用 T_c（16.5%）直接乘 D——唔係 ×(1 − t)。呢個係你第五次交手先斬嘅惡魔，唔好翻發。

Question 16 — Correct Answer: C

Model Answer (English): "Relevant costs are future, incremental cash flows plus opportunity costs. Contribution forgone from displaced regular sales is an opportunity cost — relevant. Absorbed fixed overheads, sunk development costs and allocated head office costs are not relevant."

【解題思路】 - 口訣：future + incremental + opportunity。sunk（已使）同 absorbed fixed OH（分攤）永遠 irrelevant。

Question 17 — Correct Answer: 63 days

Model Answer (English): "DIO = 219,000/1,095,000 × 365 = 73 days DSO = 150,000/1,825,000 × 365 = 30 days DPO = 120,000/1,095,000 × 365 = 40 days CCC = DIO + DSO − DPO = 73 + 30 − 40 = 63 days"

【解題思路】 - 每格 = 365 × balance ÷ flow；inventory 同 payables 對 COGS，receivables 對 sales（分母唔好亂）。最後減 DPO——唔好三條加埋（你嘅舊債：分數倒轉 + 全加）。

Question 18 — Correct Answer: HK$25.00

Model Answer (English): "P₀ = D₁/(kₑ − g) = 2.00/(0.12 − 0.04) = 2.00/0.08 = HK$25.00"

【解題思路】 - 分子係 D₁（next year dividend）唔係 D₀；分母 kₑ − g 唔好調轉。

Question 19 — Correct Answer: 3.26 years

Model Answer (English): "Discount each year's flow at 10% and accumulate: Y1: 150,000/1.1 = 136,364 → cum 136,364 Y2: 150,000/1.21 = 123,967 → cum 260,331 Y3: 150,000/1.331 = 112,697 → cum 373,028 Y4: 150,000/1.4641 = 102,452 → cum 475,480 Shortfall after Y3 = 400,000 − 373,028 = 26,972; fraction = 26,972/102,452 = 0.26 → 3.26 years"

【解題思路】 - 逐年折現累積 + 插值，唔可以一條式直出（舊債：500,000×1.1÷150,000 嗰種亂砌）。表格式計，快而準。

Question 20 — Correct Answer: B

Model Answer (English): "Sunk costs are irrelevant to the abandonment decision. Only future incremental cash flows should be considered — if the PV of continuing cash flows is below the abandonment value, the project should be abandoned regardless of how much has been spent."

【解題思路】 - Sunk cost fallacy = 因為使咗 5M 所以唔捨得停——呢個係心理陷阱。決策淨係睇將來。
